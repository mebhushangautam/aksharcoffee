## About

Akshar Coffee Shop is a complete management platform for running a coffee shop and restaurant. Built with **Laravel** and **Livewire**, it provides a modern, responsive interface for day-to-day operations — from taking orders to managing staff and inventory.

Whether you operate a single location or multiple branches, Akshar Coffee Shop gives you the tools to streamline service, improve efficiency, and grow your business.

## Key Features

- **Menu & Order Management** — Manage your menu and process orders in real time
- **Table & Reservation Management** — Handle tables, reservations, and seating
- **Kitchen Display System (KDS)** — Send orders to the kitchen digitally
- **Inventory Management** — Track stock, suppliers, and reordering
- **Staff Management** — Manage roles, permissions, and schedules
- **Analytics & Reports** — Sales, performance, and operational insights
- **Cash Register** — Cash handling and transaction management
- **Kiosk Mode** — Self-service ordering for customers
- **Multi-language Support** — Multiple languages and currencies
- **Payment Integration** — Stripe, PayPal, Mollie, Flutterwave, Paystack, Razorpay, and more

## Technology Stack

- **Framework:** Laravel
- **Frontend:** Livewire
- **Database:** MySQL / PostgreSQL
- **Web Server:** Apache / Nginx

## Requirements

- PHP >= 8.2
- MySQL >= 5.7
- Composer
- Node.js & NPM

## Installation

1. Clone the repository to your web server directory
2. Copy `.env.example` to `.env` and configure your environment
3. Run `composer install` and `npm install`
4. Run `php artisan key:generate`
5. Run migrations: `php artisan migrate`
6. Build assets: `npm run build`
7. Open the application in your browser and complete setup

## Modules
